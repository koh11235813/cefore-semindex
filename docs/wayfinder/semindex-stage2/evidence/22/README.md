## 作ったもの

- **差し込み口。** なぞり直しの `decide_interval` と `resolve` の両方に、`Node` から実機の `tracker.decision_state` と同じ形を組み立てて渡す口を置いた。シミュレータだけが知る `_Origin.hist` は渡していない。口が決め方を受けるのは、腕の選択肢と解決の時点の引き直しがそろっているときだけで、方針や決まりと並べて指定すると断る。
- **隣の組ごとの乱数の流れ。** 刻みのずれ（lag）と間隔のゆらぎ（jitter）を、(seed, 通し番号, ノード, 隣) で引き直す流れに移した。1 つの判断を変えたときに、ほかの隣の組の引きが動かないようにするため。
- **点の 1 つの定め方（`score.py`）。** 遅れと点の定めを 1 か所に置いた。重みを測る側とラベルを付ける側が同じ遅れを見るようにするため。
- **重み（`weight.py`、`weight.txt`、`weight.json`）。** 主のマスで固定 3.695 秒の腕と固定 10.043 秒の腕の点がそろう値。
- **ラベル（`label.py`、`labels.txt`、`labels_summary.csv`、`labels.sha256`）。** 2 つのマスの判断 1 回ずつに、腕 3 つ × 通し 8 回を当てて付けた正解。ラベルそのものはリポジトリの外、`/home/lab_shared/semindex-learn/ev22/` に置いた。
- **安定の計測（`stability.py`、`stability.txt`）と、観測の文字にする道（`observe.py`、`observe.txt`）。**
- **確かめの台本 5 つ。** `gate.py`（口を使わないときに答えが変わらないこと）、`statecheck.py`（欄の形）、`lagcheck.py`（隣の組ごとの流れ）、`valuecheck.py`（欄の値）、`labelcheck.py`（ラベルの道具が持つべき確かめ）。
- **文の中の数を数え直す台本（`specnums.py`、`specnums.txt`）。** `spec.md` がラベルの file から読み取って書いた数を、毎回ラベルの file から数え直す。2 つの file の sha256 が `labels.sha256` のものと違えば、何も数えずに 1 で止まる。
