perrun.py imports evidence/09's perrun.py (the all-record half of each row), evidence/05's run_all and
attrib, semindex.evalagg and semindex.evalgen. ana.py imports only csv, numpy and the standard library.

perrun.py stops before writing in two cases, both of which would otherwise corrupt a stage's polls per
run while leaving its delay right: a run whose discovery rows AGG has not seen yet ("AGG is older than
the store"), and a DONE run that folds a number of polls.csv rows other than 8, which is the one row
per directed neighbour pair of the line h0 .. h4. The fix for both is to rerun the evalagg loop and
then perrun.py. All 200 runs folded 8 rows each, 320 per stage.

perrun.py also prints on stderr how many runs have 4-hop sums from the discovery rows that differ from
attrib's own censoring chain, and the totals of `sched_regen_diff`, `head_missing_disc` and
`all_missing_disc`. All four were 0 over the 200 runs, so the headline scoring and the all-record
scoring rest on the same censoring rule, no scheduled record is missing from the aggregation, and every
run's instants are the generator's own draw.

worktree root is clean, then rm -rf .ruff_cache.
