perrun.py also imports semindex.evalgen to draw each run's record instants again for that run's own
(host, seed, k, workload) and compare them against the run's experiment description. That is the
`sched_regen_diff` column, it writes nothing anywhere, and ana.py reports its total under pass line 5.

The s7 seed-1 rows that pass line 1 reports the gate beside are read from ../16/perrun.csv as they were
committed there; no evalagg output of those stages is rebuilt here.

evalagg writes a row for a run that has no DONE marker too (status incomplete, no metric columns), so
the loop above is safe to run while a sweep is still producing runs. perrun.py leaves such a run out
of its jobs: it has no meta.json yet and the per-run computation would die on it. Its stderr prints
`dirs=` and `done=` per stage, and ana.py reports a line computed on fewer seeds than it names as
incomplete, so a partial sweep cannot be read as a pass.

If perrun.py stops with "AGG is older than the store", a run finished between the evalagg loop and
perrun.py: rerun the evalagg loop and then perrun.py. perrun.py refuses before writing, because a
run that evalagg has not seen yet would sit in perrun.csv with lat4 = n4 = polls_sent = 0 and deflate
its stage's polls per run.

perrun.py also prints on stderr how many runs have 4-hop sums from the discovery rows that differ from
attrib's own censoring chain, and the totals of `sched_regen_diff`, `head_missing_disc` and
`all_missing_disc`. All four were 0 over the 203 runs, so the headline scoring and the all-record
scoring rest on the same censoring rule, no scheduled record is missing from the aggregation, and every
run's instants are the generator's own draw.
