# evidence/17: seed を 20 増やし、固定 6.0 秒の腕を足して、もう一度読んだ（2026-11-19）

evidence/16 は「時間切れで間隔を最短へ戻す決まり（T37r）は、戻さない決まり（T37）より、固定の間隔の線に対して得が大きい」という差を 20 seed で読み、「見えなかった」と出た。残った問いは 2 つ。20 seed では足りなかっただけなのか。2 つの腕を結んだ直線は、固定の間隔が実際にたどる線と合っているのか。この段は、4 つの段に新しい seed を 20 ずつ足し、固定 6.0 秒の腕を 40 seed で測った。合否の線は run の前に `spec.md` に置き、run の途中で（数を 1 つも読む前に）読み方の追記を足した。

## 先に結論

- **新しい 20 seed だけで読み直しても、差は「見えなかった」。** 得の差（T37r − T37）は +7.0 ポイント、区間は -2.0〜+15.9 で 0 をまたぐ。この読みが、この段の答えになる（追記 2）。
- **40 seed を合わせた値は +8.4 ポイント、区間は +0.6〜+15.5。** 言葉は「見えた」になるが、これは独立した確かめになっていない。evidence/16 がすでに読んだ 20 seed を含み、前半は別の版のコードで測っている。大きさの見積もりとして置く。
- **新しい seed での確かめでは見えず、合わせた値は 0 をかろうじて外れる。** 追記 3 が「いちばん起きやすい」と書いた分かれ方が、そのまま起きた。差があるとしても 8 ポイント前後で、20 seed の区間の半幅（およそ 9 ポイント）と同じ大きさになる。
- **固定 6.0 秒の腕は、2 つの腕を結んだ直線より上（遅い側）に出た。** 新しい 20 seed で -4.9 ポイント（区間 -12.9〜+2.5）。0 をまたぐので、読みは「直線と 3 つの腕の折れ線は見分けられない」。
- **3 つの腕の折れ線に対して、T37r は「固定の折れ線より上（得がある）」と読めた。** 新しい 20 seed で +8.4 ポイント（区間 +1.7〜+14.7）。ただし、下の「読むときの注意」の 2 つ目のとおり、この 1 語は弱い。
- 120 本は全部有効。なぞり直しが言った 6.0 秒の腕（遅れ 29.744 秒、状態確認 159.4 回）に対して、実測は -1.2 % と +0.03 % で、±6 % の帯に入った。
- この問いには、これ以上 seed を足さない（`spec.md` で先に決めた）。

## 読み

- 2 つの決まりの違いは、「T37r は状態確認を 26 % 増やして、遅れを 21〜23 % 縮める」としては、どの seed の組でもはっきり出る。分からないのは、それが固定の間隔の線に沿った動きを超えているかどうか。T37r だけの得は 40 seed でも区間が 0 をまたぎ（直線に対して -1.5〜+9.4、折れ線に対して -1.1〜+11.2）、2 つの決まりの得の差は、合わせた見積もりで下の端が +0.6 と、0 のすぐ上にある。
- 動いているのは決まりの側よりも、物差しの側。固定 6.0 秒の腕の遅れは、同じ段・同じコード・同じ sweep の中で、seed 1〜20 が 29.378 秒、seed 21〜40 が 31.504 秒と 7 % 違った（状態確認の数は 159.45 と 159.70 でほぼ同じ）。切断の時刻表が seed で変わるぶんのばらつきが、決まりどうしの得の差（7〜8 ポイント）と同じ大きさで腕に乗っている。
- 直線の引き方は、読みを変えなかった。直線でも折れ線でも、得の差は +7.0 と +6.6 で、どちらも「見えなかった」。

## 読むときの注意

- **区間の取り直しのやり方を、数を見た後に 1 か所直した。** 最初の版は、1 本の乱数の流れから seed 21〜40 の組、seed 1〜40 の組の順に引いていた。`spec.md` の文は「使う seed を `default_rng(20261119)` で 2000 回取り直す」で、組ごとに新しく引く読みのほうが文に合う、と確かめ役が指摘した。直したことで動いたのは seed 1〜40 の組の区間で、その組の区間は全部の端が少しずつ動いた（合否の線 3 の得の差は +0.73〜+15.45 から +0.58〜+15.54）。点の値、seed 21〜40 の数、言葉は 1 つも変わっていない。
- **「T37r は固定の折れ線より上」は、1 つだけ出た肯定の言葉で、弱い。** 理由は 3 つ。合否の線 4 では 4 つの量に言葉を付けていて、数が多いことの補正はしていない。40 seed では同じ量の区間が 0 をまたぐ（-1.1〜+11.2）。seed 21〜40 では 6.0 秒の腕がたまたま遅く出ていて、そのぶん折れ線が上がり、決まりの得が大きく見える（直線に対する得は +5.2、折れ線に対しては +8.4）。
- **なぞり直しは、折れ線の曲がりの向きを言い当てなかった。** なぞり直しでは 6.0 秒の腕は直線より 0.9 % 上で、折れ線にすると決まりの得は 0.9 ポイントほど上がる見込みだった（追記 6）。実測の seed 21〜40 では 3.3〜3.7 ポイント上がった。ただし 6.0 秒の腕の位置そのものの区間が 0 をまたぐので、「曲がっている」とは言えない。
- 「見えなかった」は、差が無いことを示していない。点の値は 2 回とも同じ向き（+9.8、+7.0）だった。
- T37 の打ち切りの割合は、seed 21〜40 で 2.83 %（seed 1〜20 は 0.58 %）。遅れは届いたレコードだけで平均するので、打ち切りが多いと、いちばん遅いレコードが平均から抜ける。T37 の遅れは、そのぶん短めに出ている。T37r は 0 %。
- 1 つのマス（p 0.4）、1 つの負荷、1 つの切断の形だけ。負荷を替えた測りは evidence/19 で行う。
- 集計の点検の数 `hop_gap_outside_window` は、`s8t37` 684、`s8t37r` 648、`s8b6p0` 88、`s8b10p043` 44、`s8b3p695` 0。ホップごとの内訳を作るときに窓の外の判断に当たった回数で、4 ホップ先までの遅れと状態確認の数には入らない。この段ではホップごとの内訳を読んでいない。
- `main7.sh` は `PYTHONDONTWRITEBYTECODE=1` を置く。evidence/10 と evidence/16 の run には無かった（追記 8）。
