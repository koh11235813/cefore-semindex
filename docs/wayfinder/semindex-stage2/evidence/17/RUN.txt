evalagg writes a row for a run that has no DONE marker too (status incomplete, no metric columns), so
the loop above is safe to run while a sweep is still producing runs. perrun.py leaves such a run out
of its jobs: it has no meta.json yet and the per-run computation would die on it. Its stderr prints
`dirs=` and `done=` per stage, and ana.py reports a line computed on fewer seeds than it names as
incomplete, so a partial sweep cannot be read as a pass.

If perrun.py stops with "AGG is older than the store", a run finished between the evalagg loop and
perrun.py: rerun the evalagg loop and then perrun.py. perrun.py refuses before writing, because a
run that evalagg has not seen yet would sit in perrun.csv with lat4 = n4 = polls_sent = 0 and deflate
its stage's polls per run.
