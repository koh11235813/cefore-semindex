## Task

計測の回し手と、run の有効性の確認スクリプト。

- 回し手: 条件と seed の一覧を受け取り、1 回ずつ生成・実行・保存する。保存先は `/home/lab_shared/semindex-eval/<段>/p<切断率>/<seed>/`。残すのは `results.json`、各ノードの `events.jsonl`、生成した YAML とエージェント設定。`node_dirs` の残りは run ごとに消す。終わった run は飛ばすので、止まっても続きから再開できる。root で動かすのはオーケストレータ。
- 確認スクリプト: run ごとに前提を確かめ、有効か、印つきかを判定する。確かめるのは、全エージェントの起動と `counters` 行、put の成功、予定どおりのレコード生成、生成した切断の予定どおりのリンクのイベント。全体の収束は判定に使わない。

## Acceptance

確認スクリプトは、前提が崩れた run をそれぞれ正しく印つきにすることを、作った反例で確かめる（判定は完全一致）。回し手は、途中で止めて再開したときに、終わった run を飛ばし、壊れかけの run をやり直す。実機で p = 0.2 を seed 3 個だけ回して、保存先の中身と確認の結果を Resolution に記録する。
