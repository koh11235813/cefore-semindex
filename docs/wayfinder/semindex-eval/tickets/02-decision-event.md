## Task

エージェントに `decision` イベントを足す。判断した瞬間ごとに1行を `events.jsonl` に書く。判断は3種類で、状態確認の送り先と時刻、取得失敗のあとの再送の待ち時間、レコード取得の取得先と同時に送る件数。各行には、その時点で見えていた状態（隣ごとの通知された最大 seq と連続保持の範囲、未取得の件数、送っている途中の件数、直前のタイムアウトの時刻など）、選んだ行動、その行動を選んだ確率を載せる。段 1 は既定の方針のままなので、確率は 1。

方針そのものは変えない。今の挙動を、外から見える形で書き出すだけにする。
